### Featured work

#### 🏋️ OGym — AI-powered gym management and fitness platform

Built and launched a multi-tenant product as a solo founder, including a live web application and App Store mobile app. Onboarded **2 paying B2B gyms** and supported **50+ active members** across workout, nutrition, progress, and owner-management workflows.

**Built with:** Python, Django, React, PostgreSQL, AWS, OAuth 2.0, JWT, GPT Actions, Claude MCP

#### 📊 [Agent Economics](https://github.com/Harshel17/agent-economics)

A system for measuring the real cost and value of production AI agents. It connects model and infrastructure spend to executions, successful outcomes, attribution confidence, and optimization opportunities.

**Example outcome:** $11,200 monthly cost → 25,000 runs → 15,500 qualified leads → **$0.72 per successful outcome**

**Built with:** Python, FastAPI, React, TypeScript, SQLAlchemy

#### 🔎 [Meridian](https://github.com/Harshel17/meridian-demo)

A seven-step sales-research agent that emits execution, infrastructure, and business-outcome telemetry into Agent Economics—showing the full path from agent activity to measurable value.

**Built with:** Python, FastAPI, React, TypeScript, agent workflows, telemetry

#### 🚗 ReserveGuard — Multi-agent rental recovery platform

Built an operational simulator and agent layer for preventing rental-car reservation failures. The system calculates fulfillment confidence, simulates recovery strategies, coordinates customers, renters, and managers, and supports human approval and takeover.

**Built with:** Python, FastAPI, React, SQLAlchemy, voice agents, deterministic decision systems
